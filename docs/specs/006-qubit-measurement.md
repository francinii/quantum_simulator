# Qubit Measurement

Status: ready
Legacy: legacy/medicion_de_qubits.html

## Goal

Let a student prepare a qubit, choose one or two measurement bases, and watch shots collapse the Bloch vector while Qiskit-style counts build up against Born's rule.

## Behavior

- Page: back link, header, five experiment presets, setup and circuit, Bloch sphere and histogram, theory and Qiskit code, export, four rule cards, footer takeaway.
- Experiments: Definite State (|0⟩ → Z), Random Outcome (|+⟩ → Z), The Basis Matters (|+⟩ → X), Collapse Persists (|+⟩ → Z → Z), Incompatible Bases (|0⟩ → Z → X). The active one is highlighted when state and bases match. Starts on Random Outcome.
- Setup: prepare one of |0⟩, |1⟩, |+⟩, |−⟩, |+i⟩, |−i⟩ or Ry(θ) (θ slider 0-180°, shown only for Ry); first basis Z, X or Y (→ c₀); second basis None, Z, X or Y (→ c₁).
- Any setup change cancels the running shot, clears the counts and rebuilds circuit, code and theory.
- Circuit: wire |0⟩ with the preparation gates (X, H, S, S†, Ry), one meter per measurement labeled with its basis, a classical register of 1 or 2 bits showing `?` until read, and a photon that travels to each meter. Stage label: Ready, Next shot…, Preparing…, Measurement 1, Between measurements, Measurement 2, Result read.
- Animated shot: travel, collapse (the vector eases to the measured end of the basis axis), optional second travel and collapse, hold. The meter pulses while measuring. Auto-run starts a new shot 0.35 s after the previous one; Pause stops auto-run. "1 shot" runs one animated shot. "shots = 1024" runs 1024 instantly. Reset clears counts. Speed 0.5x-3x.
- Bloch sphere: the active basis axis is drawn thick in its color with both ends labeled; other axes are thin. The caption follows the shot (Prepared state, Measuring in Z…, Collapsed to |1⟩).
- Histogram: bars for outcomes `0 1` (or `00 01 10 11` with two measurements, key = c₁c₀), counts on top, measured % / theory % below, dashed theory line, total shots; the bit-order note shows only with two measurements.
- Theory: P(+) and P(−) for the first measurement; with two, the second measurement's probabilities given each first result; a line saying the first result is certain or random.
- Qiskit code: equivalent circuit (preparation, basis rotations, measures, simulator comment) with light syntax coloring and a Copy button that reads "Copied!" for 1.5 s.
- Last-shot line: describes the last shot or "Ran N shots instantly…".
- Export GIF (540x540): 8 random shots, each prepared → collapse (→ second collapse), with the histogram filling, looping; status text while it works. File name `qubit_measurement.gif`.

## Technical decisions

- Measurement math is pure TypeScript in `shared/lib/quantum`: Bloch-vector helpers (dot, scale, normalize), probability of the + end of an axis, collapse target, sequential outcome probabilities, shot sampling with an injectable random source.
- The shot animation is a pure state machine in the feature `lib/` (stages, durations, easing, photon position), tested without React.
- Qiskit code is generated by a pure function and tested on exact text.
- Second use of the Bloch sphere: sphere, equator, projection and state arrow move to `shared`; each simulator keeps its own axes. Superposition is refactored onto them and must stay pixel-identical.
- `ExportBar` gains a standalone variant (own card, no top border); `PanelHeader` gains an optional color dot.
- The two histograms (this and superposition) stay separate: their legacy layouts differ.
- Setup chips stay in the feature until a second simulator needs them.
- The animated shot never runs while the user prefers reduced motion: Auto-run starts paused.

## Out of scope

- More than two measurements, more than one qubit, running real Qiskit.
- High-DPI canvas scaling.

## Acceptance criteria

- [ ] Math tests: P(+) is 1, 0.5, 0 for |0⟩, |+⟩ on Z/X and |+⟩ on Z; collapse targets are the ± axis ends; sequential probabilities sum to 1 and match Experiments 4 and 5 (|+⟩ Z→Z gives 00 and 11 only; |0⟩ Z→X gives 50/50 on c₁).
- [ ] Sampling with a fixed random source is deterministic; 10,000 shots land within tolerance of theory.
- [ ] Shot state machine: stage order and durations for one and two measurements, easing endpoints, photon position per stage.
- [ ] Qiskit code text is exact for every state and basis, including Ry(θ) in radians with four decimals.
- [ ] Each experiment sets state and bases as listed and highlights itself; manual setup clears the highlight when it no longer matches.
- [ ] Any setup change cancels the shot and clears counts.
- [ ] 1 shot adds exactly one count when it finishes; 1024 shots add 1024 instantly; Reset clears.
- [ ] Auto-run starts shots until paused; speed scales the animation.
- [ ] Histogram shows 2 or 4 bars with correct keys, counts, measured and theory percentages and theory lines.
- [ ] Bloch caption, active axis and highlighted pole follow the shot stages.
- [ ] Copy puts the code text on the clipboard and shows "Copied!" for 1.5 s.
- [ ] Exported GIF has 88 frames (one measurement) or 136 (two), 540x540, looping, and the button is disabled while exporting.
- [ ] All controls are keyboard operable with visible labels.
- [ ] Side by side with the legacy page, layout, colors and texts match.
- [ ] Auto-run starts paused under reduced motion.
- [ ] Superposition and interference still pass their tests and look unchanged.
